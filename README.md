# Piles et accumulateurs

Fiche de révision de physique-chimie (Terminale pro) pour le chapitre **« Stocker l'énergie
électrique avec un système électrochimique »**.

En ligne : https://skavyoy8.github.io/sciences-piles-accus/

Le contenu reprend uniquement les fiches du chapitre : la feuille de cours, l'activité 1
(réaliser une pile Daniell), l'activité 2 (étudier un accumulateur au plomb), le TP « piles citron
et patate » et la page d'exercices « Je teste mes acquis ».

## Contenu

- **Le cours** : réaction d'oxydoréduction, pile, accumulateur, tableau charge / décharge,
  formules `Q = I × t` et `E = Q × U` avec leurs unités.
- **La pile Daniell** : protocole, mesure (1,1 V), Doc. 1, schéma et équation-bilan.
- **L'accumulateur au plomb** : batterie 12 V / 64 Ah / 768 Wh, protocole, mesures avant et après
  la charge, cycle charge / décharge.
- **Piles citron et patate** : bornes + et −, 0,32 V pour un citron, 0,64 V pour deux en série.
- **Exercices** : QCM corrigé, pile au citron, pile zinc/argent, lampe à manivelle.
- Un QR code en bas de page pour ouvrir le site sur un téléphone.

## Technique

- Un seul fichier `index.html` : HTML et CSS, sans JavaScript ni image.
- Schémas en SVG dessinés dans la page ; la pile Daniell d'ouverture est animée (les électrons
  circulent du zinc vers le cuivre), animation coupée si « réduire les animations » est activé.
- Police Instrument Sans (Google Fonts), mode sombre automatique, lisible sur téléphone.
- Code couleur constant : cuivre pour la borne +, gris-bleu zinc pour la borne −.
